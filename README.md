# Annoying Dog

Interactive DELTARUNE animated sprites for your VS Code sidebar. Select your favorites, drag them anywhere, and they'll stay exactly where you left them.

## Features

- 🐶 **Animated Sprites**: Classic animations from Undertale and DELTARUNE.
- 🎨 **Customizable Selection**: Choose exactly which sprites you want to see.
- 🖱️ **Drag & Drop**: Reposition any sprite anywhere in the view.
- 💾 **Persistence**: Your custom layout and selection are saved automatically across sessions.
- 🎭 **Special Guests**: Includes animations like Jevil and Mr. "Ant" Tenna.

## How to Use

1. Click on the **Annoying Dog** icon in the Activity Bar (Side Bar) or find it in the Explorer view.
2. Open the Command Palette (`Ctrl+Shift+P` or `Cmd+Shift+P`).
3. Search for **Annoying Dog: Select Sprites**.
4. Select/Deselect the characters you want to display and press `Enter`.
5. Drag the sprites to arrange them as you like!

## Configuration

The extension stores your preferences in VS Code's global storage, so your dogs will be waiting for you exactly where you left them every time you open the editor.
